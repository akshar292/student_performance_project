# 🎓 StudentIQ - Student Performance Intelligence & Prediction Platform

StudentIQ is an AI-powered academic performance platform built with Python, Streamlit, Scikit-Learn, Plotly, and SQL.

## Features
- 🏠 **Dashboard**: Real-time KPI metrics, city-wise scores, and pass/fail ratio.
- 📊 **Analytics**: Factor analysis (attendance, study hours, correlation heatmap, feature importances).
- 🤖 **AI Prediction**: ML regression for score prediction & classification for Pass/Fail probability with personalized academic advice.
- 🔍 **Student Directory**: Live search & individual student scorecard radar charts.
- 🗄️ **SQL Insights**: Pre-packaged queries & custom SELECT SQL query runner.
